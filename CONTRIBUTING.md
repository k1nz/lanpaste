# Contributing

LanPaste is a Tauri 2 desktop app: a Rust core in `src-tauri/` and a Vue 3
frontend in `src/`. The marketing site in `site/` is a separate Vue app and is
built and deployed on its own.

## Prerequisites

- Node.js (LTS)
- Rust stable (`rust-toolchain.toml` pins the channel)
- Platform toolchain: Xcode command line tools on macOS, MSVC build tools and
  WebView2 on Windows

## Running it

```bash
npm install
npm run dev:tauri     # Vite plus the Tauri shell, with hot reload
```

`npm run dev` alone serves the frontend in a browser. There is no backend in
that mode, so IPC calls resolve to empty results — useful for layout work,
not for anything that talks to the store or the network.

## Building and checking

```bash
npm run typecheck     # vue-tsc
npm test              # vitest
npm run i18n:parity   # locale key sets match
npx tauri build       # production bundle

cd src-tauri
cargo test
cargo clippy
```

## Layout

| Path | What lives there |
|---|---|
| `src-tauri/src/clipboard.rs` | Clipboard capture, native read/write, paste into the frontmost app |
| `src-tauri/src/store.rs` | SQLite metadata, blob directory, content-hash dedup, retention |
| `src-tauri/src/net/` | mDNS discovery, pinned-TLS server and client, pairing, sync, file transfer |
| `src-tauri/src/{crypto,device,cleanup,i18n}.rs` | Identity, device flags, retention policy, catalogs |
| `src-tauri/src/ipc.rs` | The command surface the frontend calls |
| `src/overlay/` | The clipboard palette |
| `src/settings/` | The settings window |
| `src/shared/` | Types, i18n, IPC wrappers, formatting, design tokens |

## Conventions worth knowing before you change something

**UI work follows the design system.** Read `design-system/lanpaste/MASTER.md`
first; if `design-system/lanpaste/pages/` has a file for the surface you are
touching, that file overrides the master. The overlay is deliberately a dense,
keyboard-first palette — not a landing page.

**Every user-visible string comes from a catalogue.** Add keys to both
`src/locales/en-US.json` and `src/locales/zh-CN.json`; the two must carry
identical key sets, which `npm test` and `npm run i18n:parity` both check. The
Rust side has its own catalogues (`src-tauri/src/i18n.rs`) for tray menu items
and other native strings.

**Backend errors are codes, not prose.** Return lowercase machine-readable
strings (`offline`, `rejected`, `trust_broken`) and map them to text in
`src/shared/errors.ts`. If you add a code, add its mapping and a case in
`src/shared/errors.test.ts` in the same change — the tests assert the strings
the backend actually sends, which is how a mismatched rule was caught.

**Commits** read as an imperative sentence with a capitalised first word:
`Fix overlay action bar overlap and unify list and scrollbars.` The body
explains why the change is needed. `chore(release):` is reserved for the
release workflow's own commits.

## Releasing

Push a tag matching the version in `package.json`, `src-tauri/tauri.conf.json`
and `src-tauri/Cargo.toml`; the release workflow verifies the three agree,
builds macOS (Apple Silicon and Intel) and Windows bundles, drafts a GitHub
release with notes generated by git-cliff, and publishes it. The app version
shown in the UI is injected from `package.json` at build time, so there is no
separate copy to update.

The site is deployed from `site/` by its own workflow whenever that directory
changes on `main`.
