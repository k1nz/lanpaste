# LanPaste

[English](README.md) | **简体中文**

这边复制。那边粘贴。

LanPaste 是面向你电脑桌面的剪贴板工具，让同一 Wi‑Fi 或有线网络下的 Mac 与 Windows 设备互通剪贴板。在一台设备上复制的链接、色号、截图或文件，片刻之后即可在另一台设备上粘贴使用。历史记录在不同设备上分别保留，所有数据仅在你的本地网络中传输。无需注册账号、不依赖云端服务，也不会向互联网发送任何内容。应用常驻于菜单栏 / 系统托盘，仅在需要时可见。

## 功能特性

- **无需学习成本。** 复制与粘贴的操作方式和日常完全一致，LanPaste 只是让内容同步出现在你的其他设备上。
- **隐私优先。** 剪贴板内容只在已配对设备之间、通过你自己的网络传输。没有服务器，也没有账号。
- **历史记录可搜索。** 一个快捷键即可打开搜索浮层：找到复制的条目、预览内容，按 **Enter** 即可粘贴到当前应用。
- **大文件不占空间。** 文件仅在你执行粘贴时才下载，大视频不会悄然占满另一台设备的磁盘。

## 快速上手

1. **在两台设备上安装 LanPaste。** 前往 [Releases](https://github.com/k1nz/lanpaste/releases) 下载对应平台的版本。应用尚未签名，首次启动时系统可能会要求你允许运行——详见下文[首次启动](#首次启动)。
2. **配对设备。** 打开**设置**（托盘菜单，或在浮层中按 `⌘,` / `Ctrl+,`），进入**设备**，在**附近**列表中应能看到另一台设备。点击**添加**，输入对方屏幕上显示的 6 位数字验证码。
3. **完成。** 在一台设备上复制，即可在另一台设备上粘贴。每台设备只需配对一次。

两台设备都需要运行 LanPaste，并连接至**同一本地网络**（同一 Wi‑Fi，或连接同一路由器的有线与无线设备）。

### 首次启动

应用尚未签名，系统在首次打开时可能会提示：

- **Mac：** 前往系统设置 → 隐私与安全性 → 仍要打开；或按住 Control 键点按应用 → 打开。
- **Windows：** 若出现 SmartScreen 提示，选择「更多信息」→「仍要运行」。

## 日常使用

通过快捷键打开浮层，或点击托盘图标：

- **Mac：** Option‑Shift‑V（`⌥⇧V`）
- **Windows：** Ctrl‑Shift‑V

打开后：

- **输入关键词**搜索历史记录。
- **↑ / ↓** 切换结果，**Enter** 粘贴并关闭。
- **Esc** 关闭浮层。
- **⌘K** / **Ctrl+K** 打开更多操作：复制到本机、同步到指定设备、删除等。
- 如有需要，可按类型（文字、图片、文件等）过滤。

快捷键可在「设置 → 快捷键」中修改。

### 文件

复制文件后，另一台设备会先显示文件名与大小，文件内容在粘贴时才下载。因此，大文件在真正需要之前不会占用任何空间。若传输失败，条目会保留在历史记录中，按 **Enter** 即可重试。

### 仅发送至指定设备

默认情况下，新内容会同步到所有已配对设备。若只想发送到某台特定设备，或内容超过自动同步的大小上限，请打开 Actions → **同步到**，然后选择目标设备。离线设备无法被选中。

## 设备级控制

在「设置 → 设备」中，每台已配对设备都有独立的开关：

- **允许发送** — 本机可以将剪贴板内容推送给该设备。
- **允许接收** — 本机可以接收该设备发送的内容。
- **自动写入剪贴板** — 收到的文字等内容会立即写入系统剪贴板，无需打开浮层即可直接粘贴。文件仍然只在粘贴时才下载。

你还可以为设备添加**备注**（仅自己可见），或**移除**设备。移除后，需要重新配对才能继续共享内容。

在「设置 → 存储与清理」中，可以设定自动同步的内容大小上限（默认 20MB），以及历史记录的保留量（默认 500 条 / 1GB）。

## 隐私

LanPaste 不设账号，也不连接任何服务器；内容只在你已配对的设备之间、通过你的本地网络传输。

配对依赖对方屏幕上显示的短码，任何能看到该屏幕的人都可能输入这个验证码，因此请确保在两台设备前完成配对。配对成功后，各设备会记住对方，直到你移除该设备。

该工具适用于你信任的网络，例如家庭或办公网络。公共 Wi‑Fi 环境不适合使用。LanPaste 无法通过互联网同步，目前也不支持 Linux 系统。
